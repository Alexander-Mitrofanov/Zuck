# Zuck web server

Static frontend for metagenomic CRISPR repeat and spacer reconstruction. The
interface follows CRISPRloci v2 and connects to a separate Zuck API and worker.

Public site: https://alexander-mitrofanov.github.io/Zuck/

The service accepts one or two FASTA/FASTQ read files, or a retained `cycles.txt`
file. It provides job progress, cancellation, private recovery links, group and
sequence search, and authenticated result downloads. A synthetic precomputed
example can be explored even when the analysis service is unavailable.

## Development

Serve this directory with `python3 -m http.server 5173 --bind 127.0.0.1`.
`config.js` points at a loopback development API. Run `npm test` and
`npm run check`; no package installation or frontend framework is required.

## GitHub Pages

Set repository variable `ZUCK_API_BASE_URL` to the HTTPS API base address
(including its `/zuck` prefix), and select GitHub Actions as the Pages source.
The workflow tests and copies only static application assets into `dist/`.
No backend code, server configuration, credentials, uploads, or job data belong
in this repository. Recovery capabilities appear only in URL fragments and
Authorization headers, never in API query strings.

## Interpretation

Groups represent repeat/spacer content; spacer order and complete genomic loci
are not established. Confidence indices are heuristic, not calibrated
probabilities. The example is synthetic, generated by Zuck, and labeled as such.
